End-to-end music analytics project using Python, SQL, Power BI, Tableau and Machine Learning to analyze streaming performance, hit prediction, Sanremo Festival and Eurovision trends.

## Data Availability

The raw datasets are not fully included in this repository to keep the project lightweight and avoid uploading large files.

The repository includes:
- processed datasets used for analysis and dashboards;
- notebooks showing the full cleaning and transformation workflow;
- SQL scripts;
- Power BI and Tableau dashboard files/screenshots.

Raw datasets can be added locally in the `data/raw/` folder to fully reproduce the pipeline.

## How to Reproduce

1. Clone the repository.
2. Open the notebooks in Google Colab or Jupyter.
3. Use the processed datasets included in the repository to review the final analysis outputs.
4. To fully rerun the entire pipeline from raw data, place the original raw datasets inside a local `data/raw/` folder.
5. Run the notebooks in numerical order.
6. Use the SQL script in MySQL Workbench to recreate the business queries.
7. Open the Power BI file from the `powerbi/` folder.
8. Open the Tableau workbook from the `tableau/` folder.
